# practica-primer-pr

Repositorio de práctica para aprender el flujo de un pull request: crear una
rama, hacer un cambio pequeño, y abrir el PR.

## Qué hace este repo

Contiene un script sencillo en `saludo.py` con una función `saludar(nombre)`
que devuelve un mensaje de banvenida, junto con sus pruebas en `test_saludo.py`.

## Cómo correr las pruebas

```bash
python3 -m unittest test_saludo.py
```
